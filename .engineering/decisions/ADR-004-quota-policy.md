# ADR-004: 50MB 内容配额（已取消）

- Status: superseded
- Date: 2026-09-15
- Context: 早期实现用账户级 50MB 当前内容配额控制成本，同时通过分片避免单个 JSON 请求过大。
- Decision: 该账户级 50MB 配额已在插件 0.3.8 中取消；当前发布不按账户累计内容拒绝。继续保留上传会话 TTL、单次请求大小、分片大小和单个对象的平台边界，并在请求超过单次边界时返回明确错误。
- Consequences: 账户可以发布超过原 50MB 总量的当前内容，也不受已发布 Note 数量限制；大内容仍必须按分片提交，超过单个请求或单个对象边界时需要拆分或减少资源。
- Verification: core 回归测试验证超过原配额的内容可以提交，且账户隔离、更新替换、删除和错误映射仍通过。
